# Handwritten Digit Recognition

Draw any digit (0-9) on the canvas and the app will predict it instantly in your browser.

**Live Demo:** https://mythri.github.io/-handwritten-digit-recognition/

## Features
- Draw digits 0-9 with mouse
- Real-time prediction using Template Matching
- Clear button to draw again
- Works on Mobile + Laptop

## Tech Used
- HTML, CSS, JavaScript
- Canvas API

## How to Use
1. Open Live Demo link
2. Draw ONE digit big in the center
3. Click Predict
4. Click Clear to try again
